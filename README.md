# Prasanjit Ratha Portfolio

Interactive portfolio converted from the original HTML page to React with Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build for GitHub deployment

```bash
npm run build
```

The production files are generated in `dist/`. For GitHub Pages, enable Pages from the repository's Actions workflow or deploy the `dist` directory with your preferred static hosting workflow.

## Upload to GitHub

```bash
git init
git add .
git commit -m "Convert portfolio to React"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```
